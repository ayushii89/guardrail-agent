# docs assets

- `trace-viewer.png` — screenshot of the Streamlit trace viewer (referenced from the
  root README). Capture it with the app running:

  ```bash
  GUARDRAIL_OFFLINE=1 streamlit run app.py
  # run a query, then macOS: Cmd+Shift+4 to grab the pipeline + answer area
  ```

- `trace-viewer.gif` (optional) — a ~10s screen recording of a query flowing through
  the pipeline. macOS: Cmd+Shift+5 records video; convert to GIF with a tool like
  Gifski or `ffmpeg`.
